# 用户指南

## 登录与注册

- 新用户可通过注册页创建账户
- 已注册用户使用用户名或邮箱登录
- 登录后可在个人设置页修改资料

## 地点管理

- 输入关键词搜索地点
- 选择结果后可加入兴趣点列表
- 兴趣点会显示在地图和列表中

## 行程规划

- 创建行程并填写名称、日期和描述
- 从兴趣点列表中添加景点
- 调整景点顺序并维护备注、交通和预算信息

## 预算管理

- 手动新增预算项
- 从行程同步预算
- 查看预算、实际支出和分类统计

## 备忘录

- 创建、编辑和删除备忘录
- 支持 Markdown 编辑与预览

## 数据导入导出

- 顶部操作栏支持导出当前账号的数据
- 导入 JSON 后会逐项写回后端
